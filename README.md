# Programación Web — grupo A

Este repositorio reúne mis actividades de la materia y una ruta personal para
aprender HTML y CSS desde cero.

## Contenido

- [`Html + Css Landing page/`](./Html%20%2B%20Css%20Landing%20page/): primera
  actividad de GrocerQuick POS.
- [`curso-html-css/`](./curso-html-css/): ejemplos, prácticas y simulacro para
  preparar el examen.

## Cómo estudiar

1. Lee la explicación de un módulo.
2. Escribe el ejemplo por tu cuenta antes de consultar el código terminado.
3. Abre el archivo `index.html` en el navegador y cambia valores para observar
   qué ocurre.
4. Resuelve el reto indicado en el README del módulo.
5. Guarda el avance con Git siguiendo la [guía de Git](./curso-html-css/GUIA-GIT.md).

El objetivo no es memorizar etiquetas o propiedades. Debo poder explicar qué
hace cada línea, elegir una estructura adecuada y corregir errores usando las
herramientas del navegador.
