# Lista de preparación para el examen

Marca una casilla solamente si puedes realizar la acción sin copiar código.

## HTML

- [ ] Escribo `doctype`, `html`, `head` y `body` en el orden correcto.
- [ ] Explico la diferencia entre etiqueta, elemento y atributo.
- [ ] Elijo entre `header`, `nav`, `main`, `section`, `article` y `footer`.
- [ ] Creo enlaces, imágenes, listas, tablas y formularios.
- [ ] Relaciono cada `label` con su `input` mediante `for` e `id`.
- [ ] Uso una clase para varios elementos y un `id` para uno único.

## CSS

- [ ] Conecto una hoja externa con `link`.
- [ ] Reconozco selectores de elemento, clase e identificador.
- [ ] Predigo qué regla gana por cascada, especificidad y orden.
- [ ] Explico contenido, `padding`, `border` y `margin`.
- [ ] Uso `display: flex` y justifico el eje principal y el secundario.
- [ ] Creo una cuadrícula con `display: grid`.
- [ ] Escribo una media query que cambie el diseño.
- [ ] Uso unidades `%`, `px`, `rem`, `vw` y `vh` con intención.

## Antes de entregar

- [ ] No hay rutas rotas ni archivos olvidados.
- [ ] La consola del navegador no muestra errores.
- [ ] La página se puede usar con teclado.
- [ ] Revisé `git status` y `git diff`.
- [ ] El mensaje del commit explica el cambio.
