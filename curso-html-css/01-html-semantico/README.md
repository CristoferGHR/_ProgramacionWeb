# Módulo 1 — HTML semántico

HTML describe el contenido. La semántica consiste en elegir una etiqueta por su
significado, no por su apariencia.

Observa `index.html` y contesta antes de modificarlo:

1. ¿Qué información pertenece a `head` y cuál a `body`?
2. ¿Por qué las recetas son `article` y no solamente `div`?
3. ¿Qué relación existe entre `href="#recetas"` e `id="recetas"`?
4. ¿Qué ocurriría si faltara el atributo `alt` de una imagen real?

## Práctica

Agrega una tercera receta que contenga:

- un encabezado;
- una lista ordenada con tres pasos;
- una abreviatura mediante `abbr`;
- un enlace que regrese al inicio.

No uses CSS todavía. Haz un commit cuando el documento tenga una estructura
clara y todas las etiquetas estén correctamente cerradas.
