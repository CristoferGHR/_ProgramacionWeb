# Módulo 3 — Flexbox

Flexbox organiza elementos en un solo eje a la vez. Si `flex-direction` es
`row`, el eje principal es horizontal. `justify-content` actúa sobre ese eje y
`align-items` sobre el eje perpendicular.

En este ejemplo Flexbox aparece en la navegación, en la presentación y en las
tarjetas. La media query cambia la dirección para que el contenido quepa en una
pantalla pequeña.

## Práctica

1. Agrega una cuarta habilidad.
2. Haz que todas las tarjetas ocupen el mismo ancho sin asignar píxeles fijos.
3. Cambia el orden visual de la ilustración en móvil con `order`.
4. Prueba anchos de 360 px y 1024 px en las herramientas del navegador.

Explica qué diferencia existe entre `gap`, `padding` y `margin` antes de hacer
el commit.
