# Módulo 5 — Formularios accesibles

Un formulario recopila datos. El navegador puede validar reglas básicas con
atributos como `required`, `type`, `minlength` y `pattern`, incluso sin
JavaScript.

Cada `label` debe apuntar al `id` de su campo. `name` identifica el dato cuando
se envía y `autocomplete` ayuda al usuario a rellenarlo.

## Práctica

1. Agrega un campo de teléfono opcional.
2. Crea un grupo de botones de radio para elegir turno matutino o vespertino.
3. Añade una casilla obligatoria para aceptar el reglamento.
4. Intenta enviar datos inválidos y anota qué valida el navegador.
5. Recorre todo el formulario usando solamente la tecla Tab.
