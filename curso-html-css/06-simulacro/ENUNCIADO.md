# Simulacro de examen — 90 minutos

Construye una página para anunciar un evento universitario. Trabaja sin copiar
los ejemplos y consulta documentación solamente si olvidas la sintaxis exacta.

## Requisitos HTML

- estructura completa del documento y título descriptivo;
- `header` con nombre del evento y navegación interna;
- `main` con una presentación y una sección de tres actividades;
- cada actividad debe ser un `article` con hora, título y descripción;
- tabla con el programa del día;
- formulario con nombre, correo y actividad elegida;
- `footer` y jerarquía correcta de encabezados.

## Requisitos CSS

- hoja externa;
- variables CSS para tres colores;
- modelo de caja predecible;
- navegación con Flexbox;
- actividades con Grid;
- estados `:hover` y `:focus-visible` visibles;
- una media query para pantallas menores a 650 px;
- ancho máximo para que el contenido no se estire demasiado.

## Git

Realiza al menos dos commits: uno para la estructura HTML y otro para los
estilos. Revisa `git diff` antes de cada commit.
