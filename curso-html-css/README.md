# Ruta de estudio de HTML y CSS

Esta ruta se creó a partir del temario y del código de clase del **grupo A**.
Los temas que aparecen en el material del profesor son:

- estructura de un documento HTML;
- etiquetas, atributos y semántica;
- encabezados, párrafos, listas, enlaces, imágenes, tablas y formularios;
- selectores, cascada y especificidad;
- modelo de caja;
- Flexbox, Grid y diseño responsivo con media queries.

## Orden de trabajo

| Módulo | Tema | Debo ser capaz de… |
| --- | --- | --- |
| 1 | HTML semántico | organizar una página sin pensar todavía en colores |
| 2 | CSS y modelo de caja | conectar CSS, seleccionar elementos y controlar espacios |
| 3 | Flexbox | alinear elementos en una fila o columna |
| 4 | Grid y diseño responsivo | crear cuadrículas que se adapten a la pantalla |
| 5 | Formularios | relacionar etiquetas y campos y aplicar estados de foco |
| 6 | Simulacro | construir una página completa sin copiar un ejemplo |

Empieza por el módulo 1 aunque ya conozcas algunas etiquetas. Cada módulo tiene
un ejemplo terminado y un reto. El simulacro contiene deliberadamente poco
código: ahí debes demostrar lo aprendido.

## Método recomendado

Para cada módulo usa tres pasadas:

1. **Comprender:** identifica la función de cada etiqueta o regla.
2. **Predecir:** antes de cambiar el código, escribe qué esperas ver.
3. **Comprobar:** recarga el navegador, compara el resultado y explica la causa.

Una sesión de 45–60 minutos es suficiente: 15 minutos de lectura, 25 de código
y 10 de explicación en voz alta. Si no puedes explicar una línea con palabras
sencillas, todavía no la dominas.
